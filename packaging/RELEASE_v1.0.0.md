## Cursor Token Usage 1.0.0

Windows taskbar widget for live Cursor token billing.

### Features
- Shows Cursor and Other model usage in the taskbar
- Polls the official Cursor API every 5 minutes
- No Python required — single portable `.exe`
- Automatic Windows startup
- Status colors: gray (under 70%), orange (70-89%), red (90%+)

### Install
1. Download `CursorTokenUsage.exe`
2. Run it once and choose **Install** (or **Run once**)
3. Widget appears left of the clock in the taskbar

### Requirements
- Windows 10/11 (64-bit)
- Cursor signed in on this PC
