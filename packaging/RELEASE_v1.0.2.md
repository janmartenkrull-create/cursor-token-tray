## Cursor Token Usage 1.0.2

Bugfix release for the Windows taskbar widget.

### Changes
- Stop the widget from jumping left and right in the taskbar
- Pin its position to the taskbar instead of chasing the system tray

### Install
1. Download `CursorTokenUsage.exe`
2. Run it and choose **Install** (or **Run once**)
3. Widget appears left of the clock in the taskbar

### Requirements
- Windows 10/11 (64-bit)
- Cursor signed in on this PC
